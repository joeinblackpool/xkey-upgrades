Patch Changes
  • [Internal] Bump react-native-web to ~0.21.4. (#51260 by @zoontek)
  • Preserve statement error codes and messages when queries run concurrently on Android and iOS, and format Android SQLite error codes as numbers. (#51082 by @savv)
  • [Android] Migrate to the Expo Modules API 2.0. Reloading the app now closes the databases that are still open, and lastInsertRowId is no longer truncated to 32 bits. (#51208 by @lukmccall)
